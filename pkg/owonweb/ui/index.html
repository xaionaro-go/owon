Native capability boundary

EXPLICIT

This console exposes every verified host path and labels the rest instead of pretending a browser action is a native device action.

  • Auto: sends the source-backed no-response candidate; firmware acceptance, changed settings, and readback are unverified.
  • Screen cursors: browser-local A/B markers report screen slots and counts. They never claim native voltage/time deltas.
  • Save/export: raw bytes and headers remain downloadable; verified screen traces also export locally as CSV/SVG. Native ADC/CSV/BMP/reference files are not exposed by the documented SCPI bridge.
  • DMM Hold: “Hold display” freezes this browser only. It does not change the instrument's measurement engine.
  • Generator: logical waveform/output convergence is shown where available; numeric readback and electrical output remain unverified.
  • Calibration/system settings: no safe, documented remote command is available, so native-panel instructions remain the source of truth.
  • Keep-awake: enabled during daemon startup by default; pass --no-keep-awake to opt out. The browser has no dedicated keep-awake control or status, and firmware acceptance is model-dependent.
